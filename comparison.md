# HTTP vs HTTPS Comparison

#### HTTP
- Uses port 80 by default.
- Does not encrypt traffic by default.
- Does not provide TLS server authentication.
- Vulnerable to traffic interception and modification.

#### HTTPS
- Uses port 443 by default.
- Encrypts communication using TLS.
- Uses certificates to authenticate the server.
- Protects data integrity during transmission.

#### TLS Security Benefits
- Encryption: Keeps transmitted data confidential.
- Authentication: Helps verify server identity.
- Integrity: Detects unauthorized data modification.

#### Conclusion
HTTPS is recommended because TLS provides encryption,
authentication, and data integrity.
