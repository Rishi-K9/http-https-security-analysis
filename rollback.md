# Rollback Plan

#### Objective
To restore the previous working configuration if deployment fails.

#### Rollback Steps
1. Keep a backup of the existing configuration.
2. Restore the previous working configuration.
3. Restart or reload the web server if required.
4. Verify that the website works correctly.
5. Check HTTPS connectivity and certificate validity.

#### Evidence Status
This document describes the rollback procedure.
Actual rollback has not been performed or verified.
